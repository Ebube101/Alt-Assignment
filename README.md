# Personal Web Project 🌐  

## **Overview**  
This project is a structured, multi-page **HTML web application** showcasing various web development techniques, including semantic HTML, form handling, navigation, and multimedia integration.  

## **Project Features**  
- 🏠 **About Me Page** – Introduces the author and includes a fragment identifier for easy navigation.  
- 📄 **Application Form** – A replica of the AltSchool application page, featuring a properly structured form.  
- 📊 **Courses Table** – Displays available courses using an accessible and responsive table format.  
- 🎬 **Media Showcase** – Utilizes various HTML media elements to convey a strong personal message.  
- 🔗 **Global Navigation** – Ensures smooth user experience across all pages.  

## **Technologies Used**  
- HTML5 (Semantic Markup)  
- CSS (Basic Styling)
